# 로빈스–먼로 확률근사 실험설계 보고서

> 실험 전에 작성한 설계 문서입니다. 실제 결과는 [02_결과보고서.md](02_결과보고서.md)에 있습니다.

## 1. 개요

이 탐구는 Robbins–Monro(1951) 확률근사법으로 **고장확률이 허용치 α에 도달하는 공구 마모 시간 θ**를 추정한다. 그리고 그 추정이 언제 수학적으로 보장되는지를 실험으로 검증한다.

- **시나리오**: AI 솔루션 기업의 신입 연구원으로서, 제조 현장에 "공구 교체 시점 자동 추정 모델"을 도입하기 전에 그 수학적 근거를 정리한 기술검토 보고서를 작성한다.
- **이론적 배경**: H. Robbins, S. Monro, *A Stochastic Approximation Method*, Ann. Math. Statist. 22 (1951) 400–407.
- **데이터**: AI4I 2020 Predictive Maintenance Dataset (`ai4i2020.csv`, 10,000행).

**연구 질문**

1. 고장확률 함수 M(x)의 식을 모른 채 0/1 고장 기록만으로 M(θ)=α인 θ를 찾을 수 있는가?
2. 논문의 어떤 조건(단조성, 유계성, 걸음 크기 a_n의 급수 조건)이 수렴을 보장하며, 각 조건은 해석학의 어떤 개념에 기대는가?
3. 조건을 하나씩 깨뜨리면 수렴은 어떻게 무너지는가?

## 2. 기술적 필요성

공구 교체 시점 문제는 공식을 모르고, 관측은 0/1로 거칠며, 실험은 비싸다. 이 세 가지가 겹치는 문제에서는 "모형을 가정하고 맞추는" 기존 방식보다 "관측하면서 다이얼을 고치는" 순차 방식이 필요하다.

| 현장의 제약 | 기존 방식의 한계 | 로빈스–먼로가 해결하는 점 |
| --- | --- | --- |
| M(x)=P(고장\|마모 x)의 식을 모름 (블랙박스) | 로지스틱·선형 회귀는 모형(식 51)을 가정해야 하고, 틀리면 θ도 틀림 | 모형 가정 없이 θ만 직접 추정 (분포무관, 5절) |
| 관측이 고장 1 / 정상 0 뿐 | 한 번의 관측으로는 확률을 알 수 없음 | 분산이 큰 이진 관측에도 수렴 보장 (4절, 식 44–48) |
| 고장률이 3.4%로 희소 | 무작위 A/B·격자 탐색은 θ에서 먼 고장 구간에 표본을 낭비 | 관측점 x_n이 θ 주변으로 모여 표본이 집중됨 |
| 고장까지 돌리는 실험은 비용이 큼 | 전수 조사 불가 | 한 번에 하나씩 관측하며 갱신, 메모리·계산량 O(1) |
| 장비마다 초기 추측이 다름 | 초기값에 민감한 방법은 재현성이 낮음 | 초기값 x₁과 무관하게 수렴 (식 10) |

따라서 실험 전에 갖춰야 할 기술적 요소는 다음 네 가지다.

1. **오라클(모의 현장)**: 고정된 CSV를 "x를 주면 0/1을 돌려주는" 순차 실험 환경으로 바꾼다.
2. **기준값(참 θ)**: 수렴 여부를 판단할 정답을 독립적으로 만든다 (등온회귀 추정).
3. **조건 점검 도구**: 단조성·M′(θ)>0·θ의 존재를 데이터로 확인한다.
4. **반복 실험 프레임워크**: 여러 번 돌려 b_n = E(x_n−θ)²를 추정한다 (논문의 수렴 척도 그대로).

## 3. 사용할 로빈스–먼로 개념

본 탐구는 논문의 **정리 2**(3절)와 **이진 관측 특수화**(4절)를 중심으로, 아래 개념을 실험 변수로 직접 사용한다.

**갱신 규칙 (식 7, 45)**

$$x_{n+1} = x_n + a_n(\alpha - y_n)$$

**정리 2** — 걸음 크기 {a_n}이 1/n형이고, Y가 유계(식 4)이며, M이 비감소·M(θ)=α·M′(θ)>0(식 33–35)이면, 초기값 x₁에 관계없이

$$\lim_{n\to\infty} b_n = \lim_{n\to\infty} E(x_n-\theta)^2 = 0$$

이고, 따라서 x_n은 θ에 확률수렴한다.

| 논문 개념 (식) | 수학적 내용 | 연결되는 해석학 개념 | 실험에서의 역할 |
| --- | --- | --- | --- |
| 회귀함수 M(x) (식 3, 47) | M(x)=E[y\|x]=F(x), 고장확률 | 함수, 분포함수 | 추정 대상의 정의 |
| 유계성 (식 4) | \|Y(x)\| ≤ C, 이진이면 C=1 | 유계수열·유계함수 | e_n ≤ (C+\|α\|)² 확보, x 범위 제한의 근거 |
| 단조성 (식 5, 33) | x<θ에서 M≤α, x>θ에서 M≥α | 단조함수 | d_n ≥ 0 → 항상 θ 쪽으로 당김 (실험 C) |
| θ의 존재 (식 34, 43) | M(θ)=α | 중간값정리, 연속성 | α가 고장률 바닥값보다 커야 함 |
| 기울기 조건 (식 35–42) | M(x)−α=(x−θ)[M′(θ)+ε(x−θ)], ε(t)→0 | 미분의 정의, 1차 근사 | θ 근처 기울기가 수렴 속도를 결정 |
| 하한 k̄_n (식 23) | inf (M(x)−α)/(x−θ) | 상한·하한(inf) | "가장 완만한 기울기"로 최악 경우 통제 |
| Σa_n² < ∞ (식 6) | 노이즈 누적 Σa_n²e_n 유한 | 급수의 수렴, p-급수 (π²/6) | θ에 **머물게** 함 (실험 A) |
| Σa_n = ∞ (식 26–27) | Σa_n/(a₁+…+a_{n−1}) = ∞ | 급수의 발산, 조화급수 | θ까지 **도달하게** 함 (실험 A, B) |
| 1/n형 수열 (식 30) | c′/n ≤ a_n ≤ c″/n | 수열의 비교, 점근적 크기 | a_n = c/n의 c 선택 (실험 A) |
| b_n의 점화식 (식 14–18) | b_{n+1}−b_n = a_n²e_n − 2a_nd_n | 점화식, 양항급수, 극한의 존재 | 수렴 지표 b_n의 정의 |
| Lemma 1 (식 19–20) | Σa_nk_nb_n<∞, Σa_nk_n=∞ ⇒ b=0 | ε-논법, 무한히 많은 n, 부분수열 | b_n→0 확인 |
| 평균제곱수렴 ⇒ 확률수렴 (식 10) | E(x_n−θ)²→0 | 수렴의 여러 종류 (체비셰프) | P(\|x_n−θ\|>ε) 측정 |
| 묶음 관측 (식 49–50) | r개 평균 ȳ_n으로 갱신 | 분산 감소 | 실험 D |

발표의 핵심 메시지는 한 줄이다: **Σa_n = ∞는 "도달"을, Σa_n² < ∞는 "안정"을 보장하고, 단조성은 "방향"을 보장한다.**

## 4. 데이터 구성과 문제의 수학적 정식화

공구 마모 시간은 논문 조건(단조성)을 만족하고, 토크·회전속도는 U자형이라 전 구간에서는 위반한다. 그래서 주 변수는 공구 마모, 토크는 반례 실험용으로 쓴다.

**데이터 구성** (`ai4i2020.csv`, 10,000행, 품질 등급 L 6,000 / M 2,997 / H 1,003)

| 열 | 범위 | 탐구에서의 역할 |
| --- | --- | --- |
| Tool wear [min] | 0–253 | **입력 x** (조절 다이얼) |
| Torque [Nm] | 3.8–76.6 | 반례 실험의 입력 (실험 C) |
| Rotational speed [rpm] | 1168–2886 | 참고 (U자형) |
| Air / Process temperature [K] | 295–314 | 미사용 |
| Type | L / M / H | 층별 비교 (실험 E) |
| Machine failure | 0/1, 평균 3.39% (339건) | **관측 y_n** |
| TWF / HDF / PWF / OSF / RNF | 46 / 115 / 95 / 98 / 19건 | 고장 원인 해석 |

**구간별 고장률 (사전 분석)**

| 공구 마모 구간 [min] | 0–180 | 180–200 | 200–220 | 220–240 |
| --- | --- | --- | --- | --- |
| 고장률 | 약 1.5–2.7% (평탄) | 3.9% | 13.8% | 22.7% |
| 표본 수 | 구간당 약 910 | 916 | 632 | 119 |

**정식화 (논문 4절 대응)**

- z: 공구가 고장 나는 마모 시간 (관측 불가, 논문의 z_n)
- x_n: n번째로 시험할 마모 시간 (우리가 고름)
- y_n = 1 (고장) / 0 (정상) (식 44의 response / nonresponse)
- M(x) = P(y=1 | x) = F(x) (식 46–47)
- α: 허용 고장확률 5% (보조 10%)
- θ: M(θ)=α인 마모 시간 = **권장 공구 교체 시점**

주의: 고장률 바닥이 약 2%이므로 α < 2%이면 θ가 존재하지 않는다(중간값정리의 전제 실패). 또한 마모 235분 이상은 표본이 적어 추정 고장률이 오히려 떨어지므로, x를 [0, 230]으로 제한한다.

## 5. 실험 설계

모든 실험은 동일한 오라클과 참 θ 위에서 돌리고, 한 번에 한 가지 논문 조건만 바꾼다(통제 변인).

### 5.1 공통 준비

1. **오라클 O(x)**: 마모 시간이 |w−x| ≤ 5분인 행 중 하나를 무작위 복원추출해 Machine failure를 반환한다. 해당 행이 없으면 가장 가까운 행을 쓴다. → E[O(x)] ≈ M(x), |O(x)| ≤ 1이므로 식 (4) 성립.
2. **참 θ**: 등온회귀(isotonic regression)로 단조 함수 M̂(x)를 적합한 뒤 M̂(θ\*)=α인 θ\*를 구한다. (실제 값: α=5%에서 θ\* = 197.3분. 설계 단계 파일럿의 "약 195분"은 덜 수렴한 값이었다.)
3. **사영(projection)**: 매 갱신 후 x를 [0, 230]으로 자른다.
4. **반복**: 조건당 R = 200회 독립 실행, 실행당 N = 3,000스텝, 난수 시드 고정.
5. **기본 설정**: a_n = c/n (c = 2000), x₁ = 100분, α = 0.05.

### 5.2 실험 목록

| 실험 | 검증할 논문 개념 | 조작 변수 | 가설 (예상) |
| --- | --- | --- | --- |
| A. 걸음 크기 | Σa_n=∞, Σa_n²<∞ (식 6, 26–27, 30) | a_n = c/n, 상수 c, c/n², c/√n, c/n^0.6 | 1/n형만 b_n→0. 상수는 θ 주변 진동, 1/n²은 θ 도달 전 정지 |
| A′. 상수 c | 1/n형의 c′, c″ (식 30) | c = 50, 200, 1000, 2000, 5000 | c가 작으면 느리고, 크면 초반 과진동 |
| B. 초기값 | x₁에 무관한 수렴 (식 10) | x₁ = 0, 100, 230 | 세 경우 모두 θ\*로 수렴, 초반만 다름 |
| C. 단조성 위반 | 조건 (5), (33) | 입력을 토크로: 전 구간 vs [40, 76.6] 구간 | 전 구간은 θ가 두 개(양쪽 꼬리)라 실패, 구간 제한 시 성공 |
| C′. θ 부재 | 중간값정리 (식 34) | α = 1% | θ 없음 → x_n이 경계 0으로 밀려남 |
| D. 묶음 관측 | 식 (49–50) | r = 1, 5, 20 (총 관측 수 동일) | r이 클수록 경로는 매끄럽지만 최종 오차는 비슷 |
| E. 등급별 θ | 분포무관성 (5절) | Type = L / M / H 별 오라클 | 등급마다 다른 θ → 등급별 교체 기준 필요 |
| F. 기준 비교 | "비용" 주장 | 같은 관측 수의 균등 격자 탐색 + 로지스틱 회귀 | R–M은 표본을 θ 근처에 모아 같은 예산에서 오차가 작거나 비슷 |

### 5.3 측정하는 것

- **b_n = E(x_n − θ\*)²**: R회 평균으로 추정, n에 따른 로그–로그 그래프 (논문의 수렴 척도 그대로).
- **P(|x_N − θ\*| > ε)**, ε = 5분: 확률수렴의 직접 확인.
- **경로 그림**: 대표 실행 5개의 x_n 궤적.
- **누적합**: Σa_n²e_n, Σa_nd_n의 부분합 — 식 (15)–(18)의 각 항이 실제로 수렴하는지 수치 확인.
- **최종 θ̂**: 평균 ± 표준편차.

## 6. 판정 기준, 한계, 진행 순서

**성공 판정**: 기본 설정에서 b_N이 단조적으로 감소하고, P(|x_N−θ\*| > 5분) < 5%이며, 조건을 깬 실험(A의 상수·1/n², C, C′)에서는 이 기준이 깨져야 한다.

| 실제 데이터는 근사적으로만 단조 | 0–180분 구간의 작은 흔들림 (1.5–2.7%) | α를 바닥값보다 충분히 크게(≥5%) 설정, 등온회귀로 단조성 점검 |
